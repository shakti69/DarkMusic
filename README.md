# DarkMusic Android App

High-performance Android music streaming application.

## Build Information
- **Version**: 1.2.6
- **Architecture**: Kotlin Multiplatform / Jetpack Compose
- **Target OS**: Android 8.0+ (API 26+)
- **APK**: DarkMusic.apk

## Installation
1. Download DarkMusic.apk.
2. Open the APK file on your Android device and tap Install.
